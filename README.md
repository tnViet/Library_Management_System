# Library Management System
Ứng dụng quản lý thư viện với JavaFX và MySQL, hỗ trợ mượn, trả sách và quản lý thành viên.
## Tính năng
- Quản lý sách
- Quản lý thành viên
- Mượn/trả sách
- Hiển thị lịch sử mượn sách
## Cài đặt
1. Cài Java 23+, javafx 23
2. Cài MySQL và tạo database
3. Xampp: https://www.apachefriends.org/download.html
4. Clone dự án:
   ```bash
   git clone https://github.com/ttViet/project.git

5. Mysql connect: https://downloads.mysql.com/archives/c-j/
## 📂 Cấu trúc thư mục

'''
src/
 ├─ controller/   # Controller
 
 ├─ dao/          # Data Access Object
 
 ├─ model/        # Model
 
 ├─ util/         # Tiện ích

MainApp.java
'''


## Sử dụng
- Đăng nhập với tài khoản admin
- Thêm, sửa, xoá sách
- Quản lý thành viên
- Xem bảng mượn trả sách
